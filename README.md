# linecount
Created for COS350

Three C programs that count the number of lines in a file and returns how fast it was


lc1.c

  Usage: lc1 file1 file2
  
  Counts the number of newline characters found in a file

  
lc2.c

  Usage: lc2 file1 file2
  
  Uses fork and exec to check the number of lines in each file

  
lc3.c

  Usage: lc3 file1 file2
  
  Uses threads to check the number of lines in each file and updates a global variable
